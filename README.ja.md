[X](https://x.com)（x.com / twitter.com）向けのユーザースクリプトです。
投稿のその場での翻訳（姉妹プロジェクト x-translator の移植）、
メディア（動画・GIF・写真）のダウンロード、インターフェースの整理を、X の
ライト・ディム・ライツアウトのテーマに合わせた 1 つの設定パネルからまとめて
設定できます。

> X Corp. / Twitter とは提携していません。

## インストール

1. ユーザースクリプトマネージャー（[Tampermonkey](https://www.tampermonkey.net/)、
   [Violentmonkey](https://violentmonkey.github.io/)、
   [ScriptCat](https://scriptcat.org/)）をインストールします。
2. raw URL からインストールします（スクリプトは `main` から自動更新されます）。

```
https://raw.githubusercontent.com/NemoKing1210/x-plus/main/x-plus.user.js
```

| マネージャー | 手順 |
|--------------|------|
| Tampermonkey | ダッシュボード → **ユーティリティ** → **URL からインストール** |
| Violentmonkey | ダッシュボード → **+** → **URL からインストール** |
| ScriptCat | raw URL で**URL からインストール** |
| 手動 | `x-plus.user.js` を開いてコピーし、新しいスクリプトを作成して貼り付け |

設定は X の左メニューの **X Plus** 項目、またはユーザースクリプトマネージャーの
メニューから開けます。

## 機能

### 翻訳

[x-translator](https://github.com/NemoKing1210/x-translator) と同じエンジンを
使用します。

- すべての投稿・返信・引用投稿のヘッダーに**翻訳**ボタン
- **X の記事**：記事ヘッダー（Grok の隣）の翻訳ボタンで段落ごとに翻訳します
  （タイトル、リスト、キャプションを含む）。リンク、改行、太字の見出しは
  そのまま残り、翻訳は各段落の下または元の位置に表示されます
- モード：ボタンをクリックしたとき、または投稿が画面に表示されたらすぐに
  **自動**翻訳（選択したアカウントのみに限定可能）
- 表示：テキストをその場で**置き換え**（既定）、または別パネルで*原文を表示*、
  *ホバーで原文をのぞく*、*原文 + 訳文の分割*表示
- プロバイダー：Google（キー不要）、DeepL、Microsoft、OpenAI 互換、Yandex、
  LibreTranslate
- アカウントごとのブロックリスト、原文言語の許可 / ブロックリスト、X がすでに
  自動翻訳した投稿のスキップ、投稿の ⋮ メニューの項目
- 翻訳エラー（「翻訳に失敗しました。もう一度お試しください。」）は既定で
  非表示です。スイッチで再表示できます
- リンクと絵文字はそのまま：URL とハッシュタグは翻訳後も崩れません
- TTL 付きのローカルキャッシュ、使用量メーター、緩やかなサイズ上限

### スクリーンショット

- 投稿ヘッダーの**翻訳**の隣にあるカメラボタン：クリック 1 回で、ページ上の
  見た目（現在のテーマ、訳文、メディア、引用、アクション行を含む）を PNG として
  クリップボードにコピーします
- 背景は設定可能：ページのテーマ（既定。PNG が透明にならないように）、白、
  黒、透明、任意の CSS カラー
- 画像の拡大率（自動、1×、2×、3×）、アクション行を残す / 切り取る、クリップ
  ボードにコピーする / ファイルとして保存する
- 動画と GIF はポスター画像としてキャプチャされます
- ブラウザーが画像をクリップボードに置けない場合（Firefox）、PNG はファイルと
  して保存されます
- 既定ではオフ

### メディアのダウンロード

- 投稿のアクションバーのボタン、および（任意で）各動画 / 写真の上のボタン
- 動画、GIF、写真。引用投稿も対象
- 動画の品質：最高、1080 / 720 / 480p まで、最小ファイル、または**毎回確認**
  （選択肢には各ビットレートのバージョンが並びます）
- 写真はオリジナルまたは大サイズ。複数ファイルは確認するかすべてダウンロード
- ファイル名テンプレート：`{user}` `{id}` `{date}` `{time}` `{n}` `{quality}`
  `{type}` `{text}`
- 進行状況の通知。X の公開 syndication エンドポイント経由でログインなしでも
  動作し、返されない投稿ではセッションにフォールバックします
- タイムライン閲覧時に大きい写真を使う（任意）。「既定」に戻す（またはメディア
  をオフにする）と X 自身の画像バージョンに戻ります
- フォトギャラリー（任意）：投稿の写真をクリックすると、X の写真ページの
  代わりに高速な全画面ギャラリーを開きます。返信やタイムラインは読み込みません。
  投稿のすべての写真とサムネイル、`←` / `→`、スワイプ、ズーム、ダウンロード、
  オリジナルを開くに対応（Ctrl / Cmd / Shift + クリックでは従来どおり X の
  ビューアーが開きます）
- 写真ビューアーのズーム：ホイール、ドラッグ、ダブルクリック、`+` / `-` / `0`、
  タッチスクリーンでのピンチ

### ショート風モード

YouTube Shorts のように、フィードを 1 投稿ずつ閲覧します（任意）。

- マウスホイールまたは `↑` / `↓`（`J` / `K` も可）で前 / 次の投稿に移動して
  中央に表示します（`Space` で進む、`Shift` + `Space` で戻る）
- 自動翻訳（翻訳 → 自動モード）を現在の投稿に限定できます。投稿が中央に
  しばらく留まってから開始するため、通り過ぎた投稿で API リクエストを消費しません。
  次の投稿は事前に翻訳でき（リクエスト 1 回、到達するまで何も表示しません）、
  切り替えが瞬時になります（既定でオン。翻訳ボタンはどこでも使えます）
- 動画は現在の投稿でのみ再生されます。隣の投稿の動画は一時停止したままになり、
  投稿から離れるとその動画も一時停止します（戻ると再生されます）
- 現在の投稿の横にある丸い ↑ / ↓ ボタンで、マウスでも前 / 次の投稿に移動
  できます
- スレッド線でつながった投稿（投稿下の返信、自身のスレッド）は 1 つの投稿と
  みなされ、まとめて強調・中央表示・移動されます
- 現在の投稿は少し大きくなり、周囲の投稿はぼかされます。サイズ、ぼかし、
  前 / 次の投稿の不透明度、切り替えの速さを調整できます
- 自動スクロール（任意）：設定した時間（1〜60 秒）後に自動で次の投稿へ進みます。
  それより長い動画は実際に最後まで再生されるまで投稿を保持し（開始の遅れ、
  バッファリング、シークで早く飛ぶことはありません）、ポインターが矢印ボタンの
  上にある間はカウントダウンが待機します。動画を一時停止するとカウントダウンも
  止まり、自動スクロールを一時停止すると動画も止まります。再開すると両方戻ります。
  進行状況は「次へ」ボタンの周りのリング、ボタンが非表示のときは投稿上部の
  バーで表示されます。表示方法は設定で切り替えられ、再生 / 一時停止ボタンは
  矢印の下にあります。キー（既定は `P`、設定で変更可能）で自動スクロールを
  一時停止 / 再開でき、バーの横の小さなチップにキーが表示されます。一時停止は
  記憶され、投稿を開いて戻ったりページを再読み込みしても維持されます
  （自動スクロールをオフにしてから再度オンにすると実行が始まります）
- 設定（ショート風タブ）または左下の `Ctrl + M` のヒント横のスイッチで有効に
  します
- フィード（ホーム、プロフィール、検索、リスト）で動作し、投稿ページでは動作
  しません。画面より高い投稿は端に達するまで通常どおりスクロールします

### インターフェース

スイッチ式の整理ルール：プロモーション投稿、表示回数、認証バッジ、Grok ボタン、
投稿ボックスとフィードのタブ、X がタイムラインに挿入する*フォローする人*ブロック、
右カラム（検索、Premium の案内、トレンド、*フォローする人*、フッターリンク）、
左メニューの項目（ロゴ、話題を検索、通知、チャット、通話、Grok、履歴、
クリエイタースタジオ、Premium、ポストボタン、アカウントメニューなど）、
およびフローティングの Grok / チャットパネル。設定にホバーするとプレビュー
でき、暗転とぼかしが消えて、パネルの後ろのページ上で対象要素が枠線で示されます
（現在非表示でも表示されます）。

スクリプト起動時には短いイントロが流れ、設定の適用中はページが一瞬凍結し、
その後画面内の投稿が次々に現れます。整理や注入されたコントロールが急に
表示されることはありません。`prefers-reduced-motion` の設定に従います。

**投稿**セクションでは、1 つの投稿とその各部分を装飾できます。投稿をカード
（枠線、塗りつぶし、影、調整可能な角の丸み）、投稿間の余白、内側の余白、
区切り線なし、文字サイズ、アバターの形（円、角丸、四角）、およびアバター、
引用投稿、画像、動画、リンクプレビュー、記事、「原文の言語」の通知、@ユーザー名、
アクションバー、表示回数、認証バッジ、Grok ボタンの非表示。

### フィルタリング

見たくない投稿を隠すためのルールビルダーです。インターフェースの整理とは
別に設定します。

- 投稿が**いずれか**のルールに一致すると非表示になります。ルール内の条件は
  **すべて**（AND）または**いずれか**（OR）で組み合わせます
- 条件は作者名、@ユーザー名、投稿テキスト、言語、メディア（写真、動画、GIF）、
  添付（リンクカード、引用投稿、投票、記事）、フラグ（プロモーション、
  認証済み作者、リポスト / 固定のコンテキスト）に対応
- テキスト演算子：含む / 含まない、単語単位、で始まる / で終わる、完全一致 /
  不一致、空 / 空でない、正規表現
- 絵文字対応：作者名や投稿テキスト内の旗や絵文字を、見たままの形で照合します
- **このページでテスト**では、保存前に一致する投稿（すでに非表示のものも含む）
  を枠線で示して数えます
- 非表示はスクロール中にリアルタイムで行われ、投稿セルごと削除するため空白が
  残りません。投稿ページで注目している投稿は決して非表示になりません
- 全体スイッチとルールごとのスイッチ

### 設定

- **Ctrl + M** で開閉（左下に控えめなヒントが表示され、一般でオフにできます）。
  左メニューの項目やユーザースクリプトマネージャーのメニューからも開けます
- タブ：**一般 · 翻訳（プロバイダーを含む） · メディア · ショート風 ·
  インターフェース · フィルタリング · キャッシュ · バックアップ · 情報**。
  変更は下書きされ、**保存**で適用されます
- インターフェースの言語：English、Русский、中文、Español、Português、Deutsch、
  Français、日本語（または自動）
- 通知：オン / オフ、表示位置、表示時間
- **バックアップ：**すべての設定を JSON でエクスポート / インポート、既定値に
  リセット

## 制限

- 記事の翻訳ではリンク、改行、**行単位**の太字 / 斜体は保持されますが、文中の
  太字や斜体の単語は訳文では通常のテキストとして表示されます。
- 保存できるのは **MP4** のバージョンのみです。X が HLS ストリームのみで公開
  している動画はダウンロード不可として通知されます。
- 制限付き投稿の GraphQL フォールバックは X の内部 API に依存しており、X が
  変更すると動作しなくなる可能性があります。主要な経路（syndication）は影響を
  受けません。
- X はマークアップを頻繁に変更します。ボタン、非表示ルール、配置が動かなく
  なった場合、調整するセレクターは
  [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#verifying-x-selectors) に記載されて
  います。
- 翻訳リクエストはブラウザーから選択したプロバイダー（既定は Google）へ送信
  されます。API キーはユーザースクリプトのストレージに保存され、JSON
  エクスポートにも含まれるため、このファイルは非公開にしてください。

## 開発

```bash
npm install
npm run build      # ビルド + ルートの x-plus.user.js / x-plus.meta.js を更新
npm run ci         # i18n と README のチェック + ビルド + 成果物の検証
npm run harness    # 手動テスト用の x.com モックページ
```
